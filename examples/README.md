# Example results

`benchmark-small-report.md`, `recommendation.json`, and `tradeoffs.png` come from the same completed `benchmark_small` run. The run used 5,000 training, 1,000 validation, and 2,000 test CIFAR-10 images with the official frozen DINOv2-B RAE integration.

These files are checked in so reviewers can inspect a real output without downloading model weights. They are hardware- and protocol-specific measurements, not universal performance claims. Synthetic smoke output is intentionally not included here.
