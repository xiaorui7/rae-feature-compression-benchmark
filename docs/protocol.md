# Pooled official RAE feature protocol (V1)

**Different from the thesis:** the thesis compressed spatial `[B,768,16,16]` latents and ran a compact denoising proxy. This benchmark compresses image-level `x = mean(RAE.encode(image), axes=(height,width))`, shape `[B,768]`. Pooling already discards spatial information. The denominator for every comparison is uncompressed pooled FP32, never the full spatial latent or original pixels. Pooled features cannot be decoded as if they were spatial latents. No DiT is trained and no image-generation metric is inferred.

The local CIFAR-10 Python archive supplies labels and stable source indices. Split seed 42 draws class-balanced train and validation from the official train set and a disjoint query sample from the official test set. `pilot`: 1000/200/200. `benchmark_small`: 5000/1000/2000. `smoke`: synthetic and never a real result. Manifests store dataset checksum, source, index, label, and ID. The official Stage-1 RAE is frozen. PIL RGB input is resized to 256 with bilinear/antialias, ToTensor [0,1]; the official wrapper handles its 224 bicubic encoder resize, HF normalization, and latent statistics. No random crop/augmentation or noise is applied. This is not an ImageNet DINOv2 linear-probe reproduction.

All methods receive `x_c = x - mu`, where `mu` comes from train pooled vectors only. PCA uses one train-only full-SVD basis (max k 256), `whiten=False`, truncated to 64/128/256. FP16 is storage-only; loaded vectors become FP32 for evaluation. Linear adapters use two biased linear layers without activation, train MSE, validation MSE early stopping, AdamW lr=0.001, weight decay=0, batch=256, max 50 epochs, patience 5, seeds 42/43/44. Purely linear reconstruction is strongly related to PCA, so no superiority is assumed. Transform/reconstruction metrics use the common unnormalized pooled `x` after inverse transform and adding `mu`.

Probe: per-method multiclass logistic regression on L2-normalized train representations, `lbfgs`, max_iter=1000, C in {0.1,1,10} selected by validation accuracy; no test fitting or selection. Exact cosine search uses FP32, train gallery, validation/test queries, block matrix multiplication, stable sample-ID tie order, and self-ID exclusion. 5-NN is majority vote among up to 5 with smallest numeric class on a tie. Class Precision@10 averages the same-label fraction among available top-10 (shorter galleries use their actual count). NeighborOverlap@10 compares sample IDs to the full pooled baseline, not semantic ground truth. Zero vectors become zero after safe L2 normalization.

Pooled MSE = sum over all query vector elements of `(x - x_hat)^2` divided by number of elements. Relative squared error = `sum ||x-x_hat||^2 / (sum ||x||^2 + epsilon)`, epsilon=1e-12. Paired 95% percentile bootstrap resamples the same test query IDs for method-minus-baseline accuracy and class P@10 (2000 resamples, seed 2026). It conditions on the fixed train/gallery; adapter seed variation is reported separately. Pilot's 200 queries imply 0.5 percentage point resolution per image.

Default recommendation uses *validation* class P@10, allowing at most a 2 percentage point drop from full pooled FP32, then minimizes measured serialized deployment bytes. The test result is an audit after selection, not a tiebreak. A request for strictly smaller deployment bytes can yield `no_feasible_compression`. Two percentage points are an illustrative tolerance, not a statistical guarantee.

Deployment bytes = serialized gallery representation file (including IDs/labels) + serialized encoder-side compressor state + pooled train mean. Inverse-side state, full checkpoint, original training feature caches, encoder weights, decoder, and probe classifier are separate. Raw vector bytes are also reported. Search always casts FP16 storage to FP32, so do not infer halved search RAM. Break-even is `ceil(extra fixed state bytes / positive per-vector saving)` and is an analytical estimate, not a measured scale experiment. Real time/memory are hardware-specific. Search excludes encoder and query projection. No automatic data-size reduction or paid cloud compute is used.

Results have `synthetic`, `pilot`, `actual_measurement`, or `not_run_*` statuses. Existing thesis metrics are historical/unverified with respect to this new protocol. Changing preprocessing, model hashes, manifest, or schema changes cache keys/protocol identity; invalid caches are rejected.

CLI runs cap BLAS and PyTorch CPU execution at one thread for comparable local timings; extraction uses the GPU and synchronizes before/after encoding. Search/gallery load/query transform are warmed up and repeated five times; results use the median. Earlier development timings without this cap are superseded by the final evaluation pass.
Compressor fitting is a single training pass per seed, not a five-repeat latency benchmark. Reused checkpoints are validated and keep their original recorded fit time when available; the pipeline does not refit a model merely to recreate a missing timing measurement.
